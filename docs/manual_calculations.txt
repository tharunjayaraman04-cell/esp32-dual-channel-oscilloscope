1. ADJUSTABLE POSITIVE DIODE CLIPPER
Vref_pot = 3.30 * (R_bottom / 10000)
V_clip_pos ≈ Vref_pot + V_D_on   (where V_D_on ≈ 0.65 V to 0.70 V for 1N4148)
Gain_dB = 20 * log10(Vpp_out / Vpp_in)

2. RC LOW-PASS FILTER (R = 10 kOhm, C = 100 nF)
fc = 1 / (2 * pi * R * C)
fc = 1 / (2 * 3.14159265 * 10000 * 0.0000001) ≈ 159.15 Hz

|H(f)| = 1 / sqrt(1 + (f / fc)^2)
At f = fc: |H(fc)| = 1 / sqrt(2) ≈ 0.7071  (-3.01 dB)

3. RC HIGH-PASS FILTER (C = 100 nF, R1 = R2 = 10 kOhm mid-rail bias)
Req = (R1 * R2) / (R1 + R2) = (10000 * 10000) / (10000 + 10000) = 5000 Ohm (5 kOhm)
V_bias_DC = 3.30 * (R2 / (R1 + R2)) = 3.30 * (10000 / 20000) = 1.65 V

fc = 1 / (2 * pi * Req * C)
fc = 1 / (2 * 3.14159265 * 5000 * 0.0000001) ≈ 318.31 Hz

|H(f)| = (f / fc) / sqrt(1 + (f / fc)^2)
At f = fc: |H(fc)| = 1 / sqrt(2) ≈ 0.7071  (-3.01 dB)

4. LM358 NON-INVERTING AMPLIFIER (Rf = 2.2 kOhm, Rg = 10 kOhm)
Av = 1 + (Rf / Rg)
Av = 1 + (2200 / 10000) = 1 + 0.22 = 1.22
Gain_dB = 20 * log10(1.22) ≈ +1.73 dB
